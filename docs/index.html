デスクトップの編集環境。

機能を増やすのではなく、ファイルを開いて書き、保存するまでの流れを短くしました。

フォルダを開いて、すぐ書く

ワークスペースのフォルダを選ぶだけで、配下の Markdown を一覧表示。Finder からのドラッグ＆ドロップにも対応します。

リッチテキストと Markdown を往復

見出し、リスト、引用、表、リンクをリッチテキストで編集。Markdown ソースは常にその場で確認できます。

ローカルファイルへ自動保存

編集内容は少しの待ち時間でファイルへ直接保存。保存状態と最終保存時刻を画面下で確認できます。

外部変更を検知して安全に保存

他のエディタによる変更や削除を監視。競合時は上書き・再読み込み・キャンセルを選べます。

ABC 記法の楽譜を再生

```abc ブロックをその場で描画。再生、一時停止、停止、テンポ調整までアプリ内で完結します。

ネイティブな書き出しとメニュー

Markdown、HTML、JSON、Quarto、Plain Text へ保存パネルから書き出し。ファイル／編集／表示メニューとショートカットを備えます。

はじめる

3ステップで、書き始められる。

インストール後のセットアップはありません。既存の Markdown フォルダをそのまま使えます。

STEP 01

フォルダを選ぶ

原稿を置いているフォルダを開きます。配下の .md / .markdown が一覧に並びます。

STEP 02

書いて、整える

リッチテキストで書き、必要なら Markdown ソースを確認。表やリンク、コードブロックもツールバーから挿入できます。

STEP 03

保存して、持ち出す

自動保存でファイルへ反映。配布や入稿用に、必要な形式へネイティブ保存パネルから書き出せます。
